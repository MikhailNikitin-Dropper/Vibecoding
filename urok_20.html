Как это работает

Запрос — метод и адрес, ответ — код и JSON

Метод говорит, что сделать, адрес — с чем. Всё, что после ?, — уточнения запроса.

GET /books
Получить список книг. С уточнениями: /books?q=гарри&limit=5
GET /books/7
Получить книгу №7
POST /books
Создать книгу. Её данные — в теле запроса, в JSON
DELETE /books/7
Удалить книгу №7
В ответе — код и обычно JSON. 200 — готово, 201 — создано, 204 — готово, а показывать нечего, 404 — не найдено, 422 — данные не прошли проверку.
Новый инструмент

FastAPI: функция и табличка над ней

Метод и адрес пишем «табличкой» над обычной функцией — это декоратор. Функция возвращает словарь, а FastAPI превращает его в JSON.

PYTHON
from fastapi import FastAPI app = FastAPI() # сам сервис @app.get("/") # табличка: GET-запросы на адрес / — к функции ниже def root(): return {"message": "Привет!"} # словарь → JSON

FastAPI

Библиотека для адресов: табличка, функция, ответ в JSON.

Uvicorn

Сервер: держит сервис включённым на 127.0.0.1:8000 и передаёт ему запросы.

Swagger UI

Четыре адреса библиотеки

Один ресурс — книги, /books. Разные методы — разные действия. Это карта нашего сервиса.

Разбор кода

Нет книги — raise, а не return

find_book ищет книгу по номеру. Не нашёл — raise HTTPException: дальше функция-адрес не выполняется, а клиент получает код 404.

PYTHON
def find_book(book_id): # книга по номеру — или ответ 404 con = connect() row = con.execute("SELECT * FROM books WHERE id = ?", (book_id,)).fetchone() con.close() if row is None: raise HTTPException(status_code=404, detail="Книга не найдена") # raise, а не return return dict(row) # строка базы → словарь → JSON … @app.get("/books/{book_id}") # GET /books/7 — книга №7 def get_book(book_id: int): # int: FastAPI сам превратит «7» в число и проверит его return find_book(book_id)
def, а не async def: модуль sqlite3 не умеет ждать через await. Обычную функцию FastAPI сам запустит так, чтобы она не задерживала другие запросы.

Разбор кода

Параметры функции — уточнения в адресе

Параметров q, genre и limit нет в адресе /books — значит, FastAPI берёт их из строки после ?. Значение по умолчанию делает параметр необязательным.

PYTHON

Разбор кода

Pydantic-модель — анкета для книги

Каждое поле класса — вопрос анкеты, Field — правило ответа. FastAPI сам читает JSON из тела запроса, сверяет его с анкетой и только потом вызывает add_book.

PYTHON

Как читать ответ 422

Теперь в той же книге поставьте "year": 3000 и снова нажмите Execute. Сервис не пустил книгу в базу и объяснил почему:

JSON
{"detail": [{ "type": "less_than_equal", "loc": ["body", "year"], "msg": "Input should be less than or equal to 2026", "input": 3000, … }]}
detail

Сначала проверки, потом деньги школы

Сначала всё, что ничего не стоит: есть ли книга, нет ли уже описания, есть ли ключ, не исчерпан ли лимит. И только потом — запрос к DeepSeek.

Проверка · вопрос 1

Угадайте коды ответов

Вопрос 1

В каталоге есть книга №7. Клиент по очереди отправил четыре запроса: ① GET /books/7; ② POST /books с телом {"title": "", "author": "Ученик", "year": 2025, "genre": "повесть"}; ③ DELETE /books/7; ④ снова GET /books/7. Какой код придёт на каждый и почему?

① 200 и книга в JSON. ② 422: название — пустая строка, а анкета требует хотя бы 1 символ; в loc — body и title, в базу ничего не попало. ③ 204: книга удалена, тела у ответа нет. ④ 404 «Книга не найдена»: find_book не нашёл строку и сделал raise.

Проверка · вопрос 2

Почему только fastapi dev

Вопрос 2

Одноклассник хочет открыть свой каталог с телефона и запускает fastapi run library_api.py вместо fastapi dev. Чем это опасно именно для нашего сервиса?

fastapi dev слушает только 127.0.0.1 — к сервису обращается лишь этот компьютер. fastapi run слушает 0.0.0.0: сервис открыт всем, кто может связаться с компьютером по сети, — всей домашней сети, а в кафе или другом общественном месте с Wi-Fi, возможно, и чужим людям. У DELETE защиты нет — любой из них удалит книги, не назвавшись. Сначала нужны вход и права — это урок 21.

Отладка

Почему сервис капризничает

client.py: 422 даже на правильной книге
Книга ушла не как JSON: в requests.post нужен json=, а не data=.
client.py: «Нет связи», «не ответил» или JSONDecodeError, а /books в браузере открывается
Вероятно, мешает прокси или VPN. Во втором терминале выполните $env:NO_PROXY='127.0.0.1,localhost' (на macOS — export NO_PROXY=127.0.0.1,localhost) и снова python client.py. Действует только в этом терминале.
«гарри» не находит «Гарри»
DeepSeek вернул LIKE или встроенный lower() из SQLite. Сверьте с промптом правки 1.
ProgrammingError про поток (thread)
Одно соединение на весь сервис. Попросите открывать connect() в каждой функции.
В коде .dict(), @validator или class Config
Это старый стиль Pydantic v1. Попросите переписать в стиле v2: model_dump(), Field.
NameError после правки — файл пришёл не целиком: «Верни весь файл, без пропусков». Ошибка 401 или 402 у AI — сообщите школе.

Привычки автора сервиса

01 · Одно действие — один адрес
Метод, адрес и функция. GET только читает: всё, что меняет книги или тратит ключ, — POST или DELETE.
02 · Проверяет сервис, а не клиент
Анкета Pydantic не пускает неверные данные в базу. Ответ 422 читаем: loc → msg.
03 · Своё соединение на каждый запрос
Открыли, выполнили, закрыли. Значения — только через ?.
04 · Только 127.0.0.1
fastapi dev, а не fastapi run: у сервиса пока нет защиты.
05 · Клиент не ждёт вечно
timeout=5 в каждом запросе и понятное сообщение, если сервис молчит.
