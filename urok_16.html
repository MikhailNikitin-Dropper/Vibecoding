Как это работает

Круг репетитора: задание → ответ → вердикт

Репетитор крутит один и тот же круг, а рядом всегда открыт чат с учителем.

  1. «Новое задание» — нейросеть придумывает задание в JSON по примерам
  2. Вы отвечаете в форме и нажимаете «Проверить»
  3. Нейросеть пересчитывает задание калькулятором и выносит вердикт ✅ или ❌
  4. Программа записывает результат в progress.json — слабые темы попадут в следующее задание и в подсказки учителя
Как это работает

Задание со скрытым ответом

Нейросеть возвращает задание не текстом, а данными — четырьмя полями JSON.

JSON
{ "topic": "проценты", "question": "Сколько будет 15% от 2400?", "answer": "360", "hint": "1% — это 2400 : 100." }
Программа показывает question, прячет answer, держит hint на случай ошибки и по topic считает прогресс. Ответ лежит в st.session_state и на страницу не выводится.

Промпт #1 · разминка

task_gen.py: задания в JSON

Чат DeepSeek не закрывайте до конца урока: в нём же соберём репетитора.

→ Новый чат DeepSeek
Ты — опытный Python-разработчик и наставник школьника. Напиши task_gen.py на openai SDK — генератор заданий для школьника в JSON. - клиент: OpenAI(api_key=os.getenv("DEEPSEEK_KEY"), base_url="https://api.deepseek.com"), ключ из .env через load_dotenv() из python-dotenv - TASK_PROMPT: «Ты придумываешь задания для школьника 12–15 лет. Каждый раз — новое короткое задание с одним точным ответом, без вариантов ответа. Подсказка помогает, но не раскрывает ответ. topic — тема в 1–3 словах, строчными буквами. Верни json: {"topic": "тема", "question": "задание", "answer": "ответ", "hint": "подсказка"}» - EXAMPLES — словарь «предмет → список из двух словарей» с полями topic | question | answer | hint, ровно такие: Математика: проценты | Сколько будет 15% от 2400? | 360 | 1% — это 2400 : 100. Математика: дроби | Сколько будет 3/4 + 1/8? | 7/8 | Приведите дроби к знаменателю 8. Русский язык: -тся и -ться | Вставьте пропущенное: «Завтра мы будем учи…ся». | учиться | Задайте к глаголу вопрос: что делать? Русский язык: безударные гласные | Вставьте букву: з…мля. | земля | Подберите проверочное слово. Английский язык: present simple | She ___ (play) tennis every Sunday. | plays | He, she, it — окончание -s. Английский язык: неправильные глаголы | Вторая форма глагола go? | went | Окончание -ed тут не подходит. - make_task(subject): ask = f"Предмет: {subject}. Новое задание."; messages — system с TASK_PROMPT, потом для каждого примера предмета user с ask и assistant с json.dumps(пример, ensure_ascii=False), в конце user с ask. client.chat.completions.create (не client.responses): model="deepseek-flash" (не меняй имя), response_format={"type": "json_object"} (не json_schema), temperature=0.9, max_tokens=400, extra_body={"thinking": {"type": "disabled"}}. Пустой ответ, битый JSON, не словарь или любое из полей topic, question, answer, hint не строка или пустое — верни None. Иначе словарь из этих четырёх полей, topic — через .strip().lower() - для каждого предмета из EXAMPLES: task = make_task(subject); None — напечатай f"=== {subject} ===" и «Не получилось — запустите ещё раз»; иначе f"=== {subject} · {task['topic']} ===", "Задание: " + вопрос и "Ответ: " + ответ + " · Подсказка: " + подсказка Прокомментируй код для новичка. Ответь одним блоком кода.

Как это работает

Три урока в одной функции

Примеры встают в разговор парами user / assistant, как на уроке 14, — модель отвечает по образцу. JSON mode — тоже урок 14, а temperature=0.9 — творческая настройка урока 11.

PYTHON
def make_task(subject): ask = f"Предмет: {subject}. Новое задание." messages = [{"role": "system", "content": TASK_PROMPT}] for example in EXAMPLES[subject]: # примеры — как будто прошлый разговор messages.append({"role": "user", "content": ask}) messages.append({"role": "assistant", "content": json.dumps(example, ensure_ascii=False)}) messages.append({"role": "user", "content": ask}) response = client.chat.completions.create( model="deepseek-flash", messages=messages, response_format={"type": "json_object"}, # ответ — только JSON temperature=0.9, # творчески: задания каждый раз разные max_tokens=400, # JSON не оборвётся на середине extra_body={"thinking": {"type": "disabled"}}, # без размышлений )
Ответы ассистента в примерах написали мы сами. Сервер не помнит разговоров, поэтому мы подставляем «прошлый разговор» с готовыми заданиями — и модель продолжает в том же духе.
Как это работает

Ключ дома и в облаке — не в коде

Дома ключ, который выдала школа, лежит в .env, а в облаке тот же ключ — в разделе Secrets. В код и на GitHub — никогда. get_key сначала ищет ключ в Secrets, а если не нашёл — берёт из .env.

PYTHON
load_dotenv() # дома ключ лежит в .env — в папке lesson-16 def get_key(name): try: return st.secrets[name] # в облаке ключ лежит в Secrets except Exception: # Secrets нет или в них нет ключа — берём из .env return os.getenv(name) API_KEY = get_key("DEEPSEEK_KEY") if not API_KEY: st.error("Нет ключа DEEPSEEK_KEY: добавьте его в .env или в Secrets") st.stop() # без ключа дальше не идём client = OpenAI(api_key=API_KEY, base_url="https://api.deepseek.com")
Зачем try: дома файла секретов нет, и обращение к st.secrets заканчивается ошибкой. try её ловит и идёт за ключом в .env. Ключа нет нигде — страница честно скажет об этом и остановится.

Публикация дома — вместе с родителем

Аккаунт Streamlit Cloud можно завести только с 18 лет, поэтому репетитора публикует взрослый — со своих аккаунтов. Ключ DeepSeek берут тот же, что выдала школа. Командная строка не нужна.

  1. GitHub: вход или регистрация на github.com/signup → «+» → «New repository»: имя без имени ребёнка, видимость public, README → «Create repository»
