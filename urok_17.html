Как это работает

База — это таблицы

Строка — одна книга. Столбец — одно поле, у каждого свой тип: INTEGER — целое число, TEXT — текст. id — номер записи: его ставит сама база.

Тип столбца в SQLite — подсказка, а не строгое правило: в year можно записать и слово, база не возразит. Поэтому год проверяет наша программа.
Шпаргалка SQL

SQLite и пять команд SQL

SQL — язык, на котором программа говорит с базой. SQLite — база, которая живёт в одном файле и уже встроена в Python модулем sqlite3: ставить ничего не нужно.

CREATE TABLE books (…)
Создать таблицу и назвать её столбцы
INSERT INTO books (title, year) VALUES (?, ?)
Добавить строку
SELECT * FROM books WHERE year < 1950 ORDER BY year LIMIT 20
Выбрать строки: какие (WHERE), в каком порядке (ORDER BY), сколько (LIMIT). * — все столбцы
UPDATE books SET genre = ? WHERE id = ?
Изменить строки
DELETE FROM books WHERE id = ?
Удалить строки
Без WHERE команды UPDATE и DELETE касаются всех строк таблицы.

Разбор кода

connect → execute → commit → close

Четыре шага работы с базой. connect открывает файл, execute выполняет одну команду SQL, commit сохраняет изменения, close закрывает соединение.

PYTHON
con = sqlite3.connect(DB) # подключиться; нет файла — SQLite создаст его con.execute("CREATE TABLE IF NOT EXISTS games (id INTEGER PRIMARY KEY, title TEXT, genre TEXT)") games = [("Minecraft", "песочница"), ("Тетрис", "головоломка"), ("Portal 2", "головоломка")] for title, genre in games: con.execute("INSERT INTO games (title, genre) VALUES (?, ?)", (title, genre)) # значения — через ? con.commit() # сохранить изменения в файл rows = con.execute("SELECT id, title, genre FROM games").fetchall() print("Строк в таблице:", len(rows)) for row in rows: print(row[0], row[1], "—", row[2]) con.close() # закрыть соединение
Без commit() добавленные строки пропадут, когда соединение закроется: INSERT открывает изменение, а commit его подтверждает.

Как это работает

Значения — только через ?

Если собрать запрос f-строкой, апостроф в названии закроет кавычку раньше времени, и команда сломается: sqlite3.OperationalError: near "s": syntax error. А чужой ввод вообще может стать частью команды — это называется SQL-инъекция.

PYTHON
title = "Harry Potter and the Philosopher's Stone" # ❌ Запрос собран f-строкой: апостроф закроет кавычку раньше времени con.execute(f"SELECT * FROM books WHERE title = '{title}'") # ✅ Значение подставляет sqlite3 — с любыми кавычками con.execute("SELECT * FROM books WHERE title = ?", (title,))
Документация Python советует всегда подставлять значения через ?, а не собирать запрос f-строкой, чтобы избежать SQL-инъекций. Запятая в (title,) делает кортеж из одного значения.

Разбор кода

Учим SQLite русским буквам

Встроенные LIKE и lower() в SQLite работают с регистром только у латиницы: 'a' LIKE 'A' — да, а с русскими буквами так не выйдет. Поэтому подключаем функцию из Python к соединению с базой: create_function в connect().

PYTHON
def py_lower(s): # lower() из Python знает и русские буквы return s.lower() if s is not None else None def connect(): con = sqlite3.connect(DB) # нет файла — SQLite создаст его сам con.row_factory = sqlite3.Row # строки как словари: book["title"] con.create_function("py_lower", 1, py_lower, deterministic=True) # учим SQLite нашей функции return con def search_books(): con = connect() # в connect() подключена py_lower rows = con.execute( "SELECT * FROM books WHERE instr(py_lower(title), ?) > 0 " "OR instr(py_lower(author), ?) > 0 ORDER BY title LIMIT 20", (q, q), ).fetchall()
instr(текст, кусок) — место, где кусок встретился в тексте, или 0, если не встретился. Значит, > 0 — «нашёлся». q — ваш запрос: программа заранее переводит его в маленькие буквы через .lower().

LIKE и знак процента

Книги без описания выбирает WHERE description IS NULL … LIMIT ?: в поле, куда ещё ничего не записали, лежит NULL — «пусто». А подборку по тегу ищет LIKE.

PYTHON

В LIKE знак % — любое количество любых символов, _ — ровно один символ. Проценты добавляем к значению в Python, а не вписываем в SQL-строку: значение всё равно уходит через ?.

Вопрос 2

Нужны все сказки, вышедшие до 1950 года, от старых к новым. Напишите запрос по шпаргалке SQL — на листке или в заметках. Таблица — books, жанр — в столбце genre, год — в year, а два условия сразу соединяет AND. Текст в SQL пишут в одинарных кавычках.
